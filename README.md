## 🌟 Interactive Highlights & Key Features

- **🪪 3D Holographic Developer Pass (`HoloDevPass`)**:
  - Interactive physical-feel credential card with real-time mouse/touch 3D perspective tilt.
  - Prismatic rainbow diffraction foil glare shifting dynamically with cursor coordinates.
  - 180° 3D flip card effect revealing cryptographic SHA-256 hash, security clearance, and contact barcode.
  - Simulated contactless NFC tap with procedural Web Audio feedback.
  - Fullscreen inspection mode with selectable foil finishes (*Prism, Cyber Gold, Deep Matrix*).

- **⚡ Cyber Command Palette & Terminal (`Cmd + K` / `Ctrl + K`)**:
  - Global floating terminal providing keyboard shortcuts, live simulator triggers (*Laser Pointer, Confetti Blast, Cyber Curtain, Blackout, Zoom Fit*), and direct project teleportation.

- **🧪 The Living Lab — 6 Live Interactive Sandboxes**:
  1. **PostureLens AI**: Real-time on-device posture ergonomics detection.
  2. **EdgeCV Object Scanner**: Client-side WASM object and gesture bounding boxes.
  3. **CyberVault**: Offline client-side AES-128 encryption & SHA-256 signature generator.
  4. **NetPulse**: Real-time network latency, jitter, and packet simulation.
  5. **SpatialStage Controls**: Interactive 3D WebGL camera and geometry physics manipulators.
  6. **Voice Commander**: Speech recognition command simulator.

- **🔊 Procedural Web Audio Synthesizer**:
  - Zero-latency, zero-bandwidth sound generation via Web Audio API (mechanical clicks, navigation chirps, toggle shifts, NFC bips, and modal transitions).

- **🌐 Comprehensive SEO & Structured Data**:
  - Verified Google Search Console indexation.
  - Open Graph, Twitter Cards, canonical URL, and Schema.org `Person` & `WebSite` JSON-LD markup.
  - XML Sitemap and crawler-optimized `robots.txt`.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18.0 or higher recommended)
- npm or pnpm

### Installation
```bash
# Clone repository
git clone https://github.com/Fatirrr08/Portofolio.git

# Navigate to project directory
cd Portofolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The local development server will start at `http://localhost:5173/`.

### Production Build & Lint
```bash
# Lint codebase using Oxlint
npm run lint

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
